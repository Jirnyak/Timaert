# МЕГА-ТЕСТ: инструкция для глаз владельца

Составлено 2026-09-14 под HEAD `073ed87d`. Цель — **сверка, а не охота**: ниже
для каждого блока написано, что нажать и **какое число/поведение обязано быть**.
Если увиденное расходится с колонкой «должно быть» — это находка, пиши как есть.

**Почему именно сейчас.** Глазами не проверено НИЧЕГО с v85. Под зелёной сюитой
лежат непросмотренными шесть треков подряд: меню-сессия, материя/крафт, ТРУД/SP,
блок SUB, ЗЕРКАЛО и ФЛАЖОК. Сюита ловит законы; она не ловит «окно открылось не
там», «цифра не та», «ощущается мёртвым».

## 0. Запуск и логи

```bash
cd ~/Mirror/timaert
cmake --build build -j8                       # убедиться, что бинарь свежий
./build/timaert 2>&1 | tee playtest_mega.log
```

`tee` пишет файл И оставляет вывод в терминале. Старый `playtest.log` от 13 сентября при этом НЕ трогается — имя другое. Файл перезаписывается каждым
запуском — если хочешь сохранить прогон, переименуй его перед следующим.

Если игра **упадёт или зависнет** — не перезапускай сразу, сперва:

```bash
tail -40 playtest_mega.log                          # последние строки перед смертью
```

и пришли их. При зависании во втором терминале:

```bash
sample $(pgrep -n timaert) 5 -f /tmp/hang.sample && open /tmp/hang.sample
```

**Опционально, если что-то мигает/рвётся в картинке:**

```bash
export DYLD_LIBRARY_PATH=/opt/homebrew/lib     # включает слой валидации Vulkan
./build/timaert 2>&1 | tee playtest_mega.log        # ошибки печатаются как "[vk] ...VUID..."
```

**Не пугайся в логе** (это норма, я проверю сам):
- `[pause] advance_sim_steps(1) bought NO tick — mask=...` — мир честно стоит
  под открытой панелью;
- `VUID-...` только при выходе из игры — известная течь на teardown;
- `[worldgen] ...` на старте.

## 1. Клавиши (дефолты; всё, кроме Esc, перебиндивается в меню → Controls)

### На карте
| Клавиша | Что |
|---|---|
| ЛКМ | идти в клетку / выбрать поселение |
| **Space** | пауза мира |
| WASD | панорама камеры |
| колесо / средняя-правая кнопка | зум / панорама |
| **Z** | привал до полного SP |
| **Enter** | войти в клетку (спуститься в субмир) |

### В субмире (от первого лица)
| Клавиша | Что |
|---|---|
| **стрелки** | движение |
| мышь | обзор |
| **A** / ЛКМ | удар |
| **S** | каст активного спелла |
| **Space** | прыжок |
| **E** | взаимодействие |
| **H** | добыча (ТРУД — платит SP) |

### Везде
`I` персонаж · `P` армия · `B` спеллы · `E` экипировка (на карте) ·
`T` поселение · `Q` квесты · `C` кодекс · `M` карта · `K` дипломатия ·
`F3` debug-HUD · `F5` быстрое сохранение · `F9` экран загрузки ·
**`` ` `` консоль** · `Esc` меню

**Клавиши вселения НЕТ** — она умерла 2026-09-06, придёт заклинанием. Пока дверь

## 3. Маршрут

Иди по блокам сверху вниз. **После каждого блока — одна строка фидбека**, даже
если всё хорошо («блок 4 ок» достаточно).

### Блок 1 — Старт, пролог, создание персонажа
1. Новая игра. Заставка → диафильм → создание → прибытие.
2. Разложи очки на создании, посмотри лист (`I`).

| Смотреть | Должно быть |
|---|---|
| слайды пролога | листаются, не проскакивают, текст читается |
| окно прибытия (arrival) | открывается ОДИН раз, мир под ним стоит |
| лист после создания | HP/MP/SP полные, уровень 1 |

### Блок 2 — Карта: марш, грани, encounter *(трек масштабов, v93)*
1. Походи ЛКМ по клеткам. Пересеки границу биома.
2. Дождись встречи с чужим сквадом (или `spawn_squad bandit 3 5`).
3. `Z` привал, посмотри как идёт SP.

| Смотреть | Должно быть |
|---|---|
| полоса SP при марше | убывает; по рельефу дороже, по дороге дешевле |
| привал `Z` | время летит, SP доходит до максимума, потом останавливается |
| попап соседнего сквада | одна панель, ряды Talk / Trade / Attack |

### Блок 3 — ОДНА панель субъекта *(меню-трек v94, НЕ ПРОВЕРЕН)*
Это была отдельная сессия и её никто не видел.
1. Кликни по соседнему скваду → попап → зайди в его меню.
2. Кликни по **городу**, по **деревне**, по **шпилю**, по **руине**.

| Смотреть | Должно быть |
|---|---|
| панель у ВСЕХ четырёх видов | открывается у каждого, не только у города |
| набор кнопок | различается по объекту (у деревни нет того, чего там нет) |
| сетка панели | 16×16, ничего не съезжает и не обрезается |
| королевства | их НЕТ нигде — вырезаны в v94 |

### Блок 4 — Поселение, торговля, крафт, ТРУД *(материя/крафт, НЕ ПРОВЕРЕН)*
1. Войди в город (`T` или через панель; либо `tp_settlement 0`).
2. Открой прилавок, купи и продай. Посмотри стак и цену.
3. Открой крафт. Посмотри строку рецепта.
4. Выйди в субмир (`Enter`) и нажми **`H`** на дереве/кусте/залежи.

| Смотреть | Должно быть |
|---|---|
| строка рецепта | видны СОСТАВ, **ВЫХОД** и **ТРУД** — три вещи, не одна |
| цена за стак | считается за весь стак, не за штуку |
| `H` по ресурсу | добыча происходит И списывается SP |
| `H` при нулевом SP | не даёт добыть (работа без сил не делается) |

Консолью быстрее: `give gold 5000`, `items` (список id), `loot <profileId>`.

### Блок 5 — Субмир и ЗЕРКАЛО *(главный непроверенный закон)*
Закон: **тело в субмире НИЧЕГО не владеет — оно адрес своей макро-записи.**
1. Найди на карте соседний сквад лорда, встань на его клетку, `Enter`.
2. Внизу найди его спроецированное тело. Ударь его пару раз (`A`), не убивая.
3. Выйди (`Enter`), посмотри на его сквад на карте.
4. Зайди снова, убей его насмерть.

| Смотреть | Должно быть |
|---|---|
| его HP на карте после ран | **ранен ровно настолько**, насколько ты его побил |
| он же после убийства | **мёртв на карте**, сквад распался, второй раз не встаёт |
| твой опыт за килл | капнул |
| лут с трупа | ложится в твою сумку сразу |

### Блок 6 — ФЛАЖОК: вселение *(эта сессия, 3 коммита сегодня)*
Закон: **ты полностью тот, в чьём теле стоишь.**
1. В субмире рядом со спроецированным лордом наведи на него прицел и в консоли:
   `possess`
2. Посмотри полосы HUD, `I` (лист/сумка), `B` (книга спеллов), `P` (армия).
3. Выйди на карту (`Enter`). Посмотри, **где** ты вышел и **кто** ты.
4. Теперь дай убить себя, НЕ выходя из тела лорда. Надёжный способ — призвать
   заведомо сильных и стоять: `spawn bandit 25 6`, убрать руки с клавиш.
   (Если включал `godmode` — сперва `godmode off`.)

| Смотреть | Должно быть |
|---|---|
| полосы сразу после `possess` | **ЕГО**, не твои (другой максимум HP) |
| `I` / `B` / `P` | **его** лист, его сумка, его книга, его люди |
| выход на карту | вылезаешь **ТАМ, ГДЕ СТОЯЛ**, и ты ЛОРД, не ты прежний |
| твоё брошенное тело | стоит где оставил, «без сознания», никуда не идёт |
| смерть в чужом теле | **очнулся в своём теле, там где оно стояло**; игра НЕ кончилась |

5. **Отказ.** `spawn bandit` (консольный, мир его не помнит) → наведись → `possess`

| Смотреть | Должно быть |
|---|---|
| ответ консоли | `Nothing remembers that one — no record to inhabit` |
| твой флаг | не шелохнулся, ты остался собой |

6. **Гейм овер без адреса** (опционально, ломает прогон — делай последним):
   вселись в лорда, убей своё брошенное тело, потом умри в лорде → **конец игры**.

### Блок 7 — Город и замок *(генератор города; замок НЕ ПРОВЕРЕН)*
1. Войди в большой город, пройди пешком: ворота → улица → стена → **замок**.
2. Посмотри деревню изнутри (частокол, вышка, дворы, колодцы).

| Смотреть | Должно быть |
|---|---|
| стена | ОДНА куртина, улица не пересекает кладку |
| замок на стене | сидит на кладке, не висит и не утоплен |
| ворота на склоне | под перемычкой можно пройти (просвет ~5 м) |
| дворы | колодцы, плетень, ничего не торчит сквозь дома |

### Блок 8 — Полёт, дракон, царь *(трек масштабов)*
```
flight on           # в субмире
tp_settlement <id>  # к варварскому городу — там царь-крестьянин
```
Дракона искать на вершинах гор (`M` карта → горы). Ожидаемые шероховатости
**тестового контента, не баги**: драконий спрайт процедурный (Avian, без арта);
меле-мобы летуна не достают.

### Блок 9 — Сейв / лоад
1. `F5` в интересном месте (лучше — **будучи вселённым в лорда**).
2. `F9` → загрузить.

| Смотреть | Должно быть |
|---|---|
| после загрузки | ты ТОТ ЖЕ (если был лордом — остался лордом) |
| лист и уровень в HUD | те же числа, что были до сохранения |
| мир | на месте, не пересоздался |

## 4. Как давать фидбек

Мне полезнее всего в таком виде:

```
блок 6, шаг 3: вышел на карту, но полосы показывают МОИ 110, а не лордовы 78
блок 4: строки рецепта вижу состав и выход, ТРУДА не вижу вообще
блок 3: у руины панель не открылась, клик проваливается
```

Плюс `playtest_mega.log` — я его прочитаю целиком. Если что-то падало или выглядело
странно, скажи **примерное время/место** в прогоне, я найду это в логе.

**Не трать время на:** аффиксы, рекавери, звуки, частицы (дождь на 5-й день),
arrival-слайд — это отложенные хвосты, они и так в очереди.
