## Замысел одним абзацем

Система частиц уже универсальна (таблица kFxPresets + один сим + один
рендер-путь); ось достройки — не «всё есть частица», а «у мира два класса
вещества». ЭНЕРГИЯ светится и складывается (аддитив: магия, огонь, искры) —
текущий пасс для неё правильный. МАТЕРИЯ заслоняет и темнит (alpha-over:
кровь, пыль, дым, брызги) — для неё пасса нет, поэтому кровь светится как
лампа (баг трейлера). Материя литая (lighting.glsl), энергия эмиссивна по
определению. Частица-материя, коснувшись пола, ШТАМПУЕТ след на ГПУ-канвас —
частицы и следы становятся одним конвейером материи. Осадки остаются
отдельным явлением (амбиентное поле, не событие), но переезжают из
экранной плёнки в мировые ГПУ-капли.

## Вердикты владельца (2026-09-06)

- Дождь: МИРОВЫЕ капли на ГПУ в этот заход (не экранная плёнка precip.frag,
  не пул частиц). Вершинник считает позиции из instance id + время,
  depth-тест о мир.
- Свет на материю: полный litSet (shadow + point-light SSBO), как у существ.
  Перф ~бесплатен (несколько сотен мелких квадов тем же lit_surface, что
  уже жгут все существа); цена только код.
- Декали: В ДЕМО. Дизайн = процедурный ГПУ-канвас по мотивам gigahrush
  (эмерджентное накопление RGB), НЕ «осевшие частицы» и НЕ пятно в сетке
  материала.
- ВСЁ ПОПИКСЕЛЬНОЕ — НА ГПУ. CPU решает «где и что случилось» (сим частиц,
  команды штампов), ГПУ рисует каждый пиксель (штампы, накопление, чтение).
- Канвас центрируется на КАМЕРЕ, не на игроке — камера обязана быть
  отделимой (свободная камера, катсцены).
- Разрешение канваса 8 пкс/тайл; охват 1024² тайлов вокруг камеры
  (8192² RGBA8 = 256 МиБ — согласовано, память есть).
- V1 — только полы (терраин, включая полы данжей). Стены (порт
  splatAdjacentWalls на 3D-структуры) — отдельный трек после глаз.
- Следы НЕ сейвятся (декорация сессии, как SessionFeed): переживают шов
  окна, не переживают выход/загрузку. Ноль бампов сейва.
- Взводим строки: Ember (угли факелов, emit_stream готов) + Smoke (новая
  матовая строка). Пыль шагов — НЕ взводим.
- Порядок: A (blend-класс) → C (канвас+landMark) → B (Ember/Smoke) →
  D (дождь). После каждого — глаза владельца на кадры.

## Законы, портируемые из gigahrush

1. ЗАКОН НАКОПЛЕНИЯ (surface_marks.ts writeSurfacePixel): пиксель следа =
   RGBA; новая капля ВМЕШИВАЕТСЯ взвешенно по альфе
   (rgb' = (rgb·curA + new·newA)/(curA+newA)), альфа СУММИРУЕТСЯ с
   насыщением 255. Одна капля — бледный пиксель, десять — густое пятно,
   кровь поверх копоти — бурое. «Следы не копятся, а вмешиваются: расход
   считается площадью, а не боем». У нас закон исполняет фиксированный
   блендинг (alpha-over цвет + аддитивная альфа) — эмерджентность железом.
2. ЗАКОН ФОРМЫ (surface_marks.ts SHADERS[]): след = процедурный
   фрагмент-шейдер (u,v,seed)→alpha. Портируем SPLAT (fbm-края со
   щупальцами), POOL (рваная лужа смерти), DRIP (вытянутая капель),
   SCORCH/BURN (гарь) — в GLSL дословно (hash/snoise/fbm — три функции).
   Реф сам говорит: «generated pixel-by-pixel like a fragment shader» —
   мы просто возвращаем их в родной дом.
3. ЗАКОН ЭМИССИИ (blood_fx.ts): частица-материя несёт landMark
   (тип/радиус/интенсивность/вероятность) и, коснувшись пола, штампует
   след СВОИМ цветом (пер-частичный хэш-джиттер цвета — бордовый/алый).
   Смерть = POOL + веер SPLAT по соседним клеткам (spawnDeathPool);
   раненые < 50% HP капают на ходу (DRIP, бюджетный обход).
4. ЗАКОН ВЫТЕСНЕНИЯ (surface_marks.ts evictFarthest…): «уходит самое
   дальнее от свежего следа — след ставится там, где что-то происходит».
   У нас закон становится ГЕОМЕТРИЕЙ: скользящее окно канваса — что ушло
   за полкилометра от камеры, забыто. Ноль кода вытеснения.

## Архитектура

### Канвас следов (инкремент C)

- ГПУ-резидентная RGBA8-текстура 8192² (1024² тайлов × 8 пкс, 256 МиБ),
  скользящее окно вокруг КАМЕРЫ. Никогда не читается на CPU.
- Штамп = дро-колл: CPU копит команды кадра (POD 32Б: pos, radiusPx, тип,
  сид, RGB, интенсивность) → один инстансированный дро-колл микроквадов в
  канвас-текстуру (офскрин-пасс), фрагмент = портированные шейдеры формы,
  блендинг = закон накопления.
- Сдвиг: тороидальный оффсет UV + очистка въезжающих полос (приём шва
  большого окна); на пересечении шва — переезд той же пинг-понг-машинерией,
  что materialTex_.
- Чтение: mesh.frag семплит канвас по мировой позиции и вмешивает в
  альбедо ДО lit_surface() — следы литые/затенённые/лунные автоматически.
  Вне окна канваса — чистый грунт.

### Классы вещества (инкремент A)

- FxPreset.blendClass ∈ {Energy, Matter} — одна колонка таблицы.
  Blood, Dust → Matter; Ember/Smoke — Matter; остальное Energy.
- Один буфер 64КиБ: pack() кладёт энергию с головы, материю с хвоста;
  материя сортируется от камеры (back-to-front, alpha-over не коммутативен).
- Второй пайплайн: create_mesh(additive=false) + particle_matter.frag —
  без белого ядра, литой (lighting.glsl + litSet). Материя рисуется ДО
  энергии (свечение поверх крови).

### Масштаб: тысячные битвы

Обе ёмкости фиксированы И считаются площадью, не боем: канвас 256 МиБ
навсегда (насыщенный пиксель не дороже чистого), пул 2048 навсегда.
Единственный растущий с боем поток — эмиссии — гейтится дистанцией
(FX-LOD, канон «микро вокруг игрока»): полный бурст ≤ 32 тайлов от камеры,
одиночная капля ≤ 64, дальше ноль частиц, но ШТАМП НА КАНВАС ВСЕГДА
(в его радиусе) — дальняя битва закрашивает своё поле без летящих капель.
Кольцо команд штампов: кап 1024/кадр, при переполнении падают самые дальние.

### Дождь (инкремент D)

Отдельный ГПУ-пасс мировых капель: вершинник считает позицию капли из
instance id + времени (хэш-сетка в цилиндре вокруг камеры, ~4096 инстансов,
радиус ~24 тайла — уточняется глазами при заходе D), depth-тест о мир.
Ноль CPU, ноль расхода пула. Открытый вопрос захода D: «под крышей»
(капли не сталкиваются; маска высоты укрытия либо принять артефакт у
проёмов). precip.frag умирает после вердикта глазами. Снег/град — те же
инстансы, другая скорость/форма (kind уже есть в SkyContext).

## Согласованные числа

| Что | Число | Закон |
|---|---|---|
| Пул частиц | 2048 × 32Б = 64КиБ | потолок vkCmdUpdateBuffer, не трогаем |
| Канвас | 8192² RGBA8 = 256 МиБ | 1024² тайлов × 8 пкс, вокруг камеры |
| FX-LOD | 32 / 64 тайлов | полный бурст / одиночная капля / ноль |
| Кольцо штампов | 1024 команд/кадр × 32Б | переполнение роняет дальние |
| Затухание следов | v1: не гаснут | уезд окна = испарение; фейд — по глазам |
| Дождь | ~4096 инстансов, r≈24 тайла | уточнить при D |

## Спящее/отложенное этого трека

- Стены (splatAdjacentWalls на 3D-структуры) — после глаз по полам.
- Пыль шагов — вердикт «не взводим».
- Фейд следов («кровь буреет за N минут») — одна константа в семпле, по глазам.
- «Под крышей» для дождя — решается в заходе D.
- Лужи дождя / мокрость грунта — не в этом треке.
- Побочная находка из старой спеки (не терять): светящиеся окна домов
  заблокированы тем, что mgr.structures() — плоский список, не ECS
  (ECS только у трупов) — структура не может нести ecs::LightEmitter.
