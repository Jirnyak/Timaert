> Правила для КАЖДОЙ сессии по этому файлу (не повторяются в промтах):
> 1. Читать до кода: `AGENTS.md` целиком, названные разделы `CANON.md`,
>    названные строки `SKELETON.md`, названную строку `macro-registry.md`.
> 2. Протокол: план → «ок» владельца → код малыми шагами → `check` зелёный
>    после каждого → диф → коммит после «ок». Ноль предупреждений.
> 3. Вердикт только из `cmake --build <абс. путь>/build --target check`.
>    Прибор `balance_run` собирается отдельно; колонки читать ПО ИМЕНИ.
> 4. Не расширять задачу. Нашёл соседний дефект — строка в отчёте, не правка.
> 5. По окончании: строки SKELETON (ПРАВДА/РАСХОЖДЕНИЕ с `file:line`),
>    статус наряда в реестре, вердикты владельца — дословно в CANON.
>    `NEXT_SESSION.md` не трогать (живой промт другой сессии).
