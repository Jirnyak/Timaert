## Вывод

Фундаментально сломано три вещи, и все три — не баги, а отсутствующие модели.
**Первая:** макромир состоит из двух симуляций — поселенческой экономики и
передвижения NPC, — которые не разделяют ни одной строки состояния: крестьяне
«работают» таймером, караваны ходят пустыми, отношения фракций заморожены с
boot, и всё, что ты назвал недостающим (войны, лорды, культы, царь-крестьянин,
грабежи), лежит ровно в этом зазоре — их некуда воткнуть, пока зазор не закрыт
моделью «работа = перенос ресурса сущностью». **Вторая:** шина событий — на
деле потиковый буфер с нулём подписчиков в проде и 15 мёртвыми тегами из 40;
квесты, которые должны спавнить врагов, эмитят событие в пустоту. Пока шина не
станет честной (в любую из двух сторон), контекстные квесты и генератор
историй строить не на чем. **Третья:** боевой урон не имеет модели — пять
несинхронных мест вычитания hp, ноль митигации (ни брони, ни крита, ни
уклонения), четыре несовместимых правила враждебности; сюда же упирается
экипировка: надевать предмет некуда, потому что удару нечего модифицировать.
Всё остальное — включая размер main.cpp (60 % которого — смоук-харнесс),
рукописные дистанции в 22 файлах и мёртвые каноничные функции при живых
самоделках в UI — важная, но косметика: она замедляет работу, а не блокирует
контент.

Принятые решения владельца, на которых стоит этот вектор: атрибутов ровно 16
(po2, показываем только имеющие формулу); инвентарь 16×16 = 256 слотов;
RNG-контракт уже починен в этой сессии (мир seed 12345 перебазирован);
**масштаб макромира: кап активных сквадов = 16384 (2^14)** — то же золотое
число, что универсальный кап сущностей субмира (один потолок = один закон
мира), несколько тысяч стабильно; следствия: бюджетный ИИ-свип обязан стать
гарантированной ротацией с фиксированным периодом (не backlog-LOD), блипам
нужен грид-куллинг, ростеры сквадов — данные (SoldierRecord), не сущности.
Также решены и ОТГРУЖЕНЫ (a93018d): навод меча «враги приоритетно»,
запрет бесплатного фулл-хила при трате очка (хил остаётся на левелапе),
wis-дивиденд ко всем наградам XP, единый закон цены торговли
(канон харизма+торг × контекст-множитель настроения/трейта).

### Раунд проектирования 2026-08-05: видение владельца + предложения агента

**Видение владельца (траектория = вариант A, честное производство,
поэтапно):** при генерации — ресурсы (минимум: лес, камень, железо,
дерево, глина; расширяемо); деревня собирает сырьё, город комбинаторно
«крафтит» товары; товары в трёх ярусах — жизненно необходимые (еда,
кирпичи, одежда) / инструментально-развитие (инструменты, мебель) /
роскошь (украшения, статуи); потребности + спрос-предложение + локальные
рынки; у городов НАСТОЯЩЕЕ население с потребностями/ростом/счастьем/
богатством; фракция-владелец берёт налоги в свою казну контекстно из
своей политики; караван = агент ГОРОДА (цель: продать излишки, купить
нужное, вернуться с прибылью); крестьянин = агент деревни, патруль =
агент стражи, бандиты = агенты ЛОГОВА, лунатики = агенты руин — **агенты
принадлежат ландмаркам** (реф M&B, но честнее — там упрощено).

**Принятые формой предложения агента (детали обсуждаемы):**
1. **Агент = {домашний ландмарк, роль, цикл цели}** — колонки таблицы
   ландмарков вместо захардкоженных спавн-блоков npc_spawn.cpp. Рейд
   банды = «караван» логова с насильственным правилом обмена: ОДНА
   механика «пойти с целью → обмен → вернуться» для торговли, грабежа,
   патруля, сбора. (Логова как ландмарка сегодня НЕ существует — бандиты
   бездомны, спавнятся в радиусе от городов.)
2. **ОДИН словарь товаров** `{id, ярус(сырьё/жизненное/инструмент/
   роскошь), вес, базовая цена, рецепт?}` — убивает ТРИ несовместимых
   вокабуляра кода (economy resources[6]+goods[15] с float-«Weapons»,
   каталог предметов игрока с wpn_dagger). Хлеб города и хлеб в
   инвентаре — одна строка.
3. **Рецепт как строка**: входы[] → выход + человеко-дни + требуемый ВИД
   ландмарка. Зданий-симуляции в v1 нет — «где» = вид ландмарка, здания
   вырастают позже без ломки таблицы.
4. **Потребности — лестница по ярусам** (Anno/Banished-модель): нехватка
   жизненного → голод → падение населения/счастья + ФАКТ; инструменты →
   множители производства/роста; роскошь → счастье/богатство. Честность =
   сохранение потоков на агрегатах поселения, не поимённая симуляция.
5. **Казна фракции + налоговая политика из темперамента** (у Kingdom
   сегодня нет поля казны): налоги ← богатство городов; казна → жалование
   гарнизонов/армий → «не выплачено» → дезертиры (петля в №3). Стоки
   (роскошь, войны, стройки, жалование) обязательны против раздувания.

**Методика баланса:** якорная единица — человеко-день (1 еда/житель/день,
круглые числа по дому); производительность крестьянина задаёт долю
крестьян, остальное выводится. Главный инструмент — **headless-прогон
«мир играет сам в себя» на N игровых лет** с инвариантами-законами
(сохранение ресурса: произведено = потреблено + Δскладов; население в
коридоре; цены не разлетаются; ни одна деревня не вымерла без
факта-причины в хронике) + свип по сидам — по образцу смоука
macro_travel_sp, уже доказывающего закон сохранения SP на живой игре.

**Словарь фактов v1 (~12):** собрано, произведено, караван вышел/прибыл/
потерян, ограблено, голод начался, налог собран, казна пуста, жалование
не выплачено, население выросло/упало, урожай/неурожай.

**Решения владельца (2026-08-05, вторая итерация раунда):**
- **(а) РЕШЕНО: единый универсальный словарь товаров — ДА.** Уточнения
  формы: словарь — СУЩЕСТВИТЕЛЬНЫЕ мира; лут-профили / рецепты /
  потребности / ассортименты — ОТНОШЕНИЯ над ними (лут-таблица не
  умирает, ссылается на те же id — она уже строково-ссылочная).
  Процедурные предметы = **архетип в словаре + экземпляр
  {archetypeId, materialId, quality, seed}**, всё процедурное выводится
  из сида (тот же паттерн, что таблица монстров и резолвер спрайтов:
  строка каталога + пер-экземплярный контекст; арт авто-перекрывает).
  **Материалы = строки яруса «сырьё» ТОГО ЖЕ словаря**; закладка под
  будущий крафт СЕЙЧАС = колонка допустимых материалов у архетипа
  (маска), позже — рецепты + таблица множителей материал×архетип.
- **(б) РЕШЕНО: логово бандитов — ландмарк** (владелец рисует арт, по
  аналогии с городом/деревней; резолвер спрайтов перекроет процедурное
  без правки движка). Размещение — контекстные колонки строки: леса,
  близость дорог, МИНИМАЛЬНАЯ дистанция от городов и замков. В модели
  агентов: дом бандитов, «экономика» — награбленное, «караван» — рейд.
- **(б+) РЕШЕНО: замки — ландмарк СИЛЫ.** Дом военных агентов
  (патрули/гарнизон/армии), денежный узел (налог сюда, жалование
  отсюда — петля «казна пуста → дезертиры»), сиденье лорда (стыкуется с
  possession «выйти лордом»). Размещение — территория/дороги/границы
  королевства.
- **(в) РЕШЕНО: объём v1 = 5 сырья + 3 товара на ярус (14 строк);
  (г) РЕШЕНО: здания абстрактны в v1** (рецепт называет ВИД места).
