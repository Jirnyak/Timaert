## ЧТО ДЕЛАТЬ ДАЛЬШЕ — по убыванию готовности

### 1. GameEvent → срез летописи — РАЗБЛОКИРОВАН квест-ординалами

«События кадра» = срез летописи между закладками
(`EventBus::frame_first_seq` есть; history_-шина уже мертва). События ещё
возят строки (SpellCast.s1, ReputationChange.s1-фракция, ApplyEffect.s1-верб
и т.д.). `NodeContext` не видит мира — дать читающий доступ формой
`FactNaming`. Это самый тяжёлый из готовых треков — начинать свежим
контекстом, с разведки всех эмиттеров/читателей `s1`/`s2`.

### 2. Машинерия S9-переходов — ЗАКОН РЕШЁН (владелец, 2026-08-29), ждёт №1

**Переход = РЕАКЦИЯ НА ФАКТЫ летописи, не ежедневный закон-проход**
(CANON S9, уточнение записано). Ландмарки в норме — независимые модули;
переход — редкая мини-механика («иногда деревня может стать городом, но
очень редко»), расширяемая новыми реакциями. Строить ПОСЛЕ «GameEvent →
срез» его средствами. Механика готова: `lm.type = X` + `rebake_world` в
санкционированных точках (`landmark_grid.h`); Ruin/Lair/Shrine/Mine/Tower
имеют строки реестра без экземпляров. Готовые первые реакции: смерть места
(факт Died уже пишется с 2026-08-29 — честная смерть населения) → Ruin;
истощённый шпиль (depleted) → Ruin. Профиль производства при переходе
сменится сам — econSite теперь колонка реестра.

### 3. Слухи (дверь готова)

Слух = запись летописи, прочитанная чужими устами: услышал → копия в журнал
(та же дверь, что участие/локальность/одержимость). Нужна механика
ПОЛУЧЕНИЯ (таверна? встреча?) — это геймплей, вопрос владельцу.

### 4. Переезд склада HP/листа/позиции игрока (~550 мест)

Хвост «игрок = НПЦ» (память `player-squad-merge-track`): склад HP/лист/
позиция ещё в PlayerState. Отдельный заход, не смешивать с другими.

## Грабли (наследуемые + свежие 2026-08-29)

- зелёный ctest ≠ зелёная сборка: сначала `BUILD_OK`, потом вердикт;
- `%s` в printf с не-строкой компилятор не ловит;
- сравнение упакованных байтов рода летописи — только через распаковку;
- python-вырезы по индексам режут соседние функции — Edit точным текстом;
- авторские тексты (кодекс, лор) при переносе копировать ДОСЛОВНО — пересказ
  своими словами = порча канона (поймано на переносе кодекса);
- смоук `load_game` требует `open_load` перед собой в цепочке;
- поле POD-структуры при агрегатной инициализации — сверить ПОРЯДОК полей
  ({7,3,2} для {giver,bornDay,slot} — не то, что кажется).
