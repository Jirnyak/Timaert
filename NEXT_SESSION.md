## КАК РАБОТАТЬ (читать первым, это не формальность)

**Замысел и архитектура живут в голове владельца, а не в коде и не в доках.**

1. **Спрашивай владельца до правки.** Порция маленькая и согласуется:
   «беру X, причина, форма правки, чем докажу» — и ждём ответа. Одобрение
   одной правки не распространяется на следующую.
2. **Не додумывай замысел.** Найденное поведение может быть АВТОРСКОЙ
   механикой; прочитать комментарий НА МЕСТЕ ВЫЗОВА и спросить.
3. **Развилки — вариантами с ценой и рекомендацией**, решает владелец.
4. **Вердикт пишется В ФАЙЛ**, иначе всплывёт заново.
5. **Свидетель раньше правки**: красный до, зелёный после, негативный
   контроль. `cmake --build build --target check` + `sh smoke.sh all 12345`
   гонять вместе; известная красная база смоуков = SMOKE-1
   `prepare_spell_auras` (все сиды), SMOKE-2 `cast_spell` (12345).
   SMOKE-4 ЗАКРЫТ 2026-09-10 (`player_grounded()` вместо прокси) — на
   сидах 1/7/999 лишних красных больше НЕТ. Одиночный зелёный перегон
   красного = SMOKE-7.
6. **Авторские тексты владельца — ДОСЛОВНО** (Варнава — имя владельца).
7. **«Игроку X, НПЦ Y» — запрещённая рамка**: игрок особен ТОЛЬКО
   камерой/инпутом/входами.

## Грабли (не наступать)

- Ссылка на ECS-компонент НЕ живёт через симулируемый тик (спавн
  реаллоцирует; перечитывать get<> после тика). Поймано ЖИВЬЁМ в тесте
  стола: negative-control спавн после сборки AutoBattleSide инвалидировал
  бы указатель на ростер.
- Вью/читатель по снятому компоненту — МОЛЧА пустой проход; миграцию вести
  разрезом с удалением поля (компилятор = свидетель) + полный смоук-прогон.
- Тестовые таргеты линкуют ПОДМНОЖЕСТВО .cpp — inline-дверь, зовущая
  .cpp-символ, ломает линк ДРУГИХ тестов (effective_sheet_of →
  worn_bonuses → anatomy.cpp добавлена пяти таргетам). Новые двери
  макро-слоя: либо честно inline, либо проверять линк ВСЕХ таргетов.
- Смоук-«лаборатория», перекрашивающая подопытного (macro_npc_trace),
  обязана исключать носителей высших ступеней лестницы поведения — тело
  с приказом/анкетой перекраске не подчиняется.
- Мост-анестезия (проекция склад→сущность каждый тик) ЗАПРЕЩЁН — §41
  механика 1; SAVE-5 родился ровно из такого моста.
- smoke.sh фильтрует stderr до `[smoke]`; по-кадровые линейные сканы =
  тайминг-флаки (SMOKE-7); каталог/ординалы сейва: только АППЕНД (v92);
  int/int = тихий ноль; смоук-токены ПО ОДНОМУ; smoke.sh ИЗ КОРНЯ; -O3,
  не -O0; zsh ломается об `===`; perl-массоправки НЕ трогают точки
  «до создания мира» — порядок «ensure → писать через дверь» проверять
  руками.
