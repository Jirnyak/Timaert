## ГРАБЛИ ЭТОГО ТРЕКА

- **Смоук-кадры не воспроизводимы без `TIMAERT_SMOKE_SEED`** — мир каждый раз
  новый, A/B недействителен. И `TIMAERT_SMOKE_SUBPOS` у края клетки
  пересекает шов, давая разные кадры на одинаковых входах.
- **Однобиомный вид не проверяет ничего**: прибор дал 0 манифактурных
  ординалов при 13.7 % покрытия дали просто потому, что все видимые клетки
  были снегом. Сперва мерить ПОКРЫТИЕ (покрасить всю даль и посчитать
  пиксели), потом судить.
- **Свидетель, чей вердикт зависит от того, куда смотреть, — не свидетель.**
  Две формы свидетеля морского дна прошли собственный негативный контроль и
  были выброшены; работает только тождество закону.
- **`Water.heightScale = 0`** (`kConfigs@src/sub/base_generator.cpp`) — дно не
  несёт октав детали ПО АВТОРСТВУ, и плоское дно бывает честным. Рельеф дна
  берётся из манифольда.

  `TIMAERT_FAR_DEBUG`) даёт ему прибор в руки без второго бинарника.
