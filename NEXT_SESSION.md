## ЧТО ДЕЛАТЬ ДАЛЬШЕ — по убыванию готовности

### 1. Машинерия S9-переходов ландмарков — РАЗБЛОКИРОВАНА

Один ростер сделал переход записью в колонку: деревня↔город, шпиль→руина —
это `lm.type = X` + `rebake_world` в санкционированных точках
(`landmark_grid.h` их называет). Сегодня `type` пишется только при рождении;
kinds Ruin/Lair/Shrine/Mine/Tower имеют строки реестра и ни одного экземпляра
— готовые цели переходов. Истощённый шпиль = смена вида (вердикт владельца,
2026-08-28) — первый кандидат. Нужен закон, КОГДА переход случается
(пороги населения? разрушение?) — обсудить с владельцем.

### 2. Квестовая личность → ординалы — СДЕЛАНО 2026-08-29 (сейв v63)

`Quest.ordinal` из `nextQuestOrdinal` (выдаётся при ACCEPT; оффер до
принятия — проекция из сида, его личность = POD-провенанс {giver, slot,
bornDay}, он же дедуп переоффера дня — единственная живая семантика
умерших string-векторов). Кодекс = реестр `macro/codex.h`, анлок = бит по
ординалу. События Quest*/CodexUnlock несут ординал в `a`, `s1` мёртв.
№3 разблокирован. Сводка — chronicle.md.

### 3. GameEvent → срез летописи (после №2)

«События кадра» = срез летописи между закладками
(`EventBus::frame_first_seq` есть; history_-шина уже мертва). События ещё
возят строки (SpellCast.s1 и т.д.). `NodeContext` не видит мира — дать
читающий доступ формой `FactNaming`.

### 4. Слухи (дверь готова)

Слух = запись летописи, прочитанная чужими устами: услышал → копия в журнал
(та же дверь, что участие/локальность/одержимость). Нужна механика
ПОЛУЧЕНИЯ (таверна? встреча?) — это геймплей, вопрос владельцу.

### 5. Переезд склада HP/листа/позиции игрока (~550 мест)

Хвост «игрок = НПЦ» (память `player-squad-merge-track`): склад HP/лист/
позиция ещё в PlayerState. Отдельный заход, не смешивать с другими.

### 6. Отложенные решения — СПИСОК ВЛАДЕЛЬЦУ

- **civ re-tie**: слияние civ-BFS с `optical_sweep` измерено (байты поля
  идентичны, float-ульпы расходятся, замер в `zones.cpp`) — принять re-tie?
- **мосты глазами**: кинуть взгляд в игре, вердикт по виду;
- **`EconSite` → колонка реестра** (и рецепты `site=Village` — деревня
  начнёт производить одной строкой данных);
- **полы популяции**: `minPop = 10/5` в `world_tick.cpp` минтит людей —
  поселение бессмертно (дефект против S5);
- **цена микро/макро-шага по мосту** + battle-тайл под декой — клеточные
  законы (problems.md §33).

## Грабли (наследуемые, всё ещё актуальны)

- зелёный ctest ≠ зелёная сборка: сначала `BUILD_OK`, потом вердикт;
- `%s` в printf с не-строкой компилятор не ловит;
- сравнение упакованных байтов рода летописи — только через распаковку;
- python-вырезы по индексам режут соседние функции — Edit точным текстом.
