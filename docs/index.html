TIMAERT FANTASY RPG ENGINE

Custom C++23 2D Engine with Procedural Dungeon Generation, Magic Spell Particle Renderer, and JSON Sprite State Machine.

🗡️ Procedural Dungeons

BSP tree dungeon splitting algorithm creating infinite procedural rooms, corridor traps, and secret treasure chambers.

✨ Magic Particle Shaders

GPU-accelerated spell particle system rendering ethereal runes, fireballs, and bioluminescent magic circles.

📜 JSON Sprite Machine

Hot-reloadable JSON sprite sheet state machine supporting multi-frame combat and walk animations.

❓ Frequently Asked Questions (FAQ)

What is TIMAERT?

TIMAERT is a lightweight C++23 2D RPG game engine built for high-performance procedural fantasy game development.

Does TIMAERT support custom sprite sheets?

Yes! TIMAERT includes a built-in JSON sprite sheet parser and animation state machine.
